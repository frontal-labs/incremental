Set up, build, test, and contribute to Incremental.

## Setup

Requirements:

- Node 22 and pnpm 9.0.0
- Python 3.10+ (for `make test-python`)
- cargo (for `make test-rust`)
- Docker (for `make linux-gate` only)
- Network access once (for the Goose toolchain fetch)

```sh
pnpm install
make setup            # fetches Goose toolchain into .toolchain/goose/
make build            # engine + git source
```

## Repository structure

| Directory | Contents |
|-----------|----------|
| `core/` | Engine core (Goose): store, policy, protocol, CLI |
| `bindings/` | Node, Python, Rust clients |
| `adapters/` | Vitest, git, strace oracle, and build/test tool adapters |

| `spec/` | Protocol v1 and related specifications |

| `benchmarks/` | Benchmark harnesses and results |

| `docs/` | This documentation (you are here) |
| `status/` | Milestone status JSON |
| `logs/` | Test target logs (git-ignored) |

## Build & test commands

```sh
make build        # engine + git source
make all-tests    # check-spec, core, policy, protocol, bindings, vitest, oracle, e2e, adapters, mcp
make test-fuzz test-python test-git
```

Every test target depends on `build`. Combine targets in one `make` call to build once: `make test-core test-policy`.

Adapter sub-targets: `test-bazel`, `test-biome`, `test-clippy`, `test-config`, `test-env`, `test-fs`, `test-playwright`, `test-pnpm`, `test-process`, `test-protobuf`, `test-ruff`, `test-turbopack`, `test-watcher`, `test-typescript`, `test-rust`.

## Ground rules

- **Soundness first:** never skip silently
- **Deterministic:** plans are order-independent; lists are sorted
- **Protocol-first:** all access through Protocol v1; bindings are thin clients
- **Append-only log:** `tg.log` is the source of truth; indexes are disposable
- **Generic engine:** core knows nothing about Vitest, git, or tests — those are adapters

## Workflow

1. Create a branch from `main`
2. Make changes, run `make build`
3. Run relevant test targets: `make test-core test-policy`
4. Update `docs/` if behavior changed
5. Open a PR; CI runs `make all-tests` plus lint and typecheck

## Milestones & status

Milestones are tracked in [`STATUS.md`](../STATUS.md) (generated by `make status`). Open items are in [`DECISIONS.md`](../DECISIONS.md) and `spec/CHANGE_REQUESTS.md`. Per-milestone JSON lives in `status/`.

## Lint & format

This repo uses biome (`biome.json`) and rustfmt (`.rustfmt.toml`) for formatting, plus `clang-format` (`.clang-format`) for C/C++.

```sh
# Run before committing
make check        # or repo-specific lint
```

## Releases
