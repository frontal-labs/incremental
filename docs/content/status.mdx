## Name status

The project is named **Incremental** (renamed from its former name on 2026-11-04; the binary, packages, and store follow the new name). The earlier trademark, GitHub, and domain checks (DECISIONS.md D-E0-01) covered the former name only. The checks for "Incremental" are not done.

## Current implementation state

- **Protocol v1** and schemas: `spec/`
- **Conformance cases** C01–C41: `conformance/cases/` (all pass)
- **Vitest adapter cases** V01–V16: `adapters/vitest/fixtures/cases/`
- **Core** (Goose): `core/src/` — `store.goose`, `policy.goose`, `protocol.goose`, `main.goose`
- **Bindings:** Node (done), Python (done), Rust (no status record)
- **Adapters:** Vitest, git, strace oracle, MCP under `adapters/` and `mcp/`
- **Repository layout:** not a single npm workspace. `mcp/`, `adapters/*`, and `bindings/node` are separate packages with their own `package.json`
