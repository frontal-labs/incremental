#         --frozen-lockfile --ignore-scripts + `make bench-smoke`.
#       * benchmarks (manual dispatch, full=true): Node 22 + Goose +
#         pnpm + bazelisk. Runs the monorepo-independent stages
#         (committed-fixture replay 10 commits, warm-plan 10k/100k,
#         bench-summary.mjs) unconditionally; the monorepo-dependent
#         stages (fixture-install, monorepo replay loop, bench-compare)
#         and fixture-e2e run only when the monorepos/* fixtures are
#         present (hashFiles guard).
#       * Removed the truncated benchmarksmark-kill-test job (its gate0
#         criteria were deliberately removed in c9c45e3).
#
# Why the full job is split: `make bench` hard-fails when the monorepos/*
# fixtures are absent (the monorepo loop and bench-compare.mjs both exit
# non-zero on missing fixtures). The monorepos/* entries are gitlinks
# (mode 160000) with no .gitmodules mapping, so a plain GitHub checkout
# cannot fetch them. The split lets the full job pass in CI (committed
# fixture only) and run the full suite on a machine that has the fixtures
# checked out.
